Cloud and Azure Security Fundamentals

Many companies in Pakistan and globally host their infrastructure on Microsoft Azure. Therefore, job postings frequently ask for knowledge of Microsoft Sentinel and Defender.

Microsoft Security Stack

Microsoft Defender: This is the endpoint protection tool. It monitors laptops and servers for malware and suspicious activity.

Microsoft Sentinel: This is Microsofts cloud-based SIEM. It collects logs from cloud services and on-premises systems to generate security alerts.

Identity and Access Management (IAM)
IAM defines who has access to what. In Azure, you manage users, groups, and roles. A SOC analyst monitors IAM logs for unusual privilege escalations.

Logging in Azure
Azure Monitor collects activity logs. This is essentially the cloud version of Windows Event Viewer. If an unknown user tries to access storage or create a new virtual machine, an alert is generated.

Practical Tip for Beginners
Microsoft Learn offers a free SC-900 module. This requires no credit card and provides a sandbox environment. Use this to understand how the portal looks.
